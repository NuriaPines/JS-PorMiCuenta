🚀 Preparación Examen JavaScript

Este repositorio contiene la evolución de mis apuntes personales y la resolución de ejercicios clave para superar con éxito el examen de Desarrollo Web en entornos Cliente.
🎯 Objetivo del Proyecto

Dominar los pilares fundamentales de JavaScript moderno (ES6+) para resolver los cuatro grandes retos del examen:

    Juego de Dados: Lógica de clases, métodos y estados.

    Normalización de Datos: Transformación compleja de estructuras con reduce.

    Compresión de Textos: Manipulación de strings y algoritmos de optimización.

    Fechas y Validaciones: Uso del objeto Date y control de bisiestos.

📚 Bloques de Estudio y Progreso
✅ Fase 1: Cimientos y Estructuras (Completado)

    Variables y Ámbitos: Uso correcto de let, const y comprensión de tipos primitivos.

    Control de Flujo: Estructuras if/else, operador ternario y bucles (for, while, for...in/of).

    Sets (El Guardián): Gestión de colecciones únicas y limpieza de duplicados.

🔄 Fase 2: Manipulación Funcional de Arrays (En Progreso)

    Filter: Filtrado de datos por condiciones múltiples (tiradas especiales, años válidos).

    Map: Transformación masiva de datos y extracción de propiedades de objetos.

    Reduce (El Jefe Final): Implementación de acumuladores para cálculos totales y normalización de datos anidados para el Ejercicio 2 del examen.

⏳ Fase 3: Programación Orientada a Objetos (Próximamente)

    Clases y Constructores: Creación del molde Jugador y Partida.

    Herencia y Privacidad: Uso de propiedades privadas (#) y métodos de clase.

⏳ Fase 4: DOM, Eventos y Utilidades (Pendiente)

    Manipulación de Strings: Métodos esenciales para la compresión de texto.

    Listeners y Eventos: Gestión de la interactividad en el navegador.

    Fechas: Validación y cálculo de intervalos temporales.

🛠️ Herramientas Utilizadas

    JavaScript ES6+

    Node.js (Entorno de ejecución de pruebas)

    GitHub (Control de versiones)
